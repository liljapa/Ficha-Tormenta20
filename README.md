# Ficha Tormenta 20 — Online

Ficha de personagem digital para Tormenta 20, totalmente editável e com salvamento automático na nuvem.

## Funcionalidades

- 🔐 **Login com Google** — cada jogador acessa com a própria conta
- 💾 **Salvamento automático** — tudo é salvo sozinho enquanto você preenche, sem precisar clicar em nada
- 📋 **Múltiplos heróis** — crie e gerencie várias fichas na mesma conta
- ⚔️ Atributos, perícias, PV/PM, ataques, magias, inventário e muito mais
- 🌙 Modo claro/escuro

## Acesse

🔗 [fichat20online-pinocchioatelier.vercel.app](https://fichat20online-pinocchioatelier.vercel.app)

## Tecnologias

React + Vite + Firebase (Authentication e Firestore)
